## 里程碑

### M0 骨架就绪 ✅

仓库结构落地：pnpm workspaces 根 + `apps/desktop`、`packages/ai`、`packages/shared` 三个空包。

### M1 手动输入入库

范围：REQ-CAP-02、REQ-CAP-05、REQ-STORE-01、REQ-TOOL-01、REQ-DX-02。

边界：只做「桌面宠物 + 输入框」的入库闭环，**不碰分析与历史 UI**。仅支持**文字**
录入——图片、文件等类型在输入框中明确提示"暂不支持"（图片需求由 M4 选区截图承接，
剪贴板图片机制已整体移除，M4 重建）。交互方向（2026-10-16 变更）：点击桌面宠物
唤出输入框，用户手动粘贴想摘录的内容、可编辑，确认后入库；**不再有任何全局热键、
模拟复制（osascript Cmd+C）、剪贴板监听与 Accessibility 权限依赖**——这些已随旧方案
整体移除。

**交互细节**（2026-10-16 对齐）：

- **桌面宠物**：带动效角色（idle 动效素材由用户提供，其余表情状态后续迭代再补）；
  默认停靠屏幕右下角，可拖动换位置但不记忆（每次启动回默认位）；单击唤出输入框；
  系统托盘图标提供退出入口。
- **输入框**：宠物旁边弹出；确认入库后输入框内显示"✓ 已拾光"轻提示 1~2 秒并自动
  收起；Esc、失焦 / 点击空白处均可收起。
- **内容规则**：仅文字，上限 5000 字（输入时拦截，实时字数统计如 4232/5000）；
  空内容确认按钮禁用；粘贴图片 / 文件提示"暂不支持"。

### M2 查询页面

范围：REQ-UI-01、REQ-UI-02、REQ-UI-03。

边界：筛选维度为内容类型、时间范围、关键词搜索（M1 阶段 M2 仅文字类型可用，M4 截图接入后恢复文 / 图筛选）；不为分析结果预留展示位置，M6 再改布局。

**性能待办**（继承 M1 对齐结论）：M2 需处理分页 / 懒加载 / 搜索索引，避免数据量上来后查询卡顿（高频使用数月后，全文关键词搜索与列表渲染是主要风险点）。

### M3 无处不在

范围：REQ-APP-01。桌面宠物常驻 + 开机自启，重启后点击宠物仍可唤出输入框。

### M4 选区截图

范围：REQ-CAP-03。类微信全屏遮罩选区、裁剪出图入库。注意：**只入库，不理解**——图片理解是 AI 能力，归 M6。

### M5 分析流水线

范围：REQ-AI-01 ~ REQ-AI-05。LangGraph 单链（ingest → analyze）跑通，CLI 可离线重跑——`packages/ai` 的独立价值在本迭代兑现。

### M6 分析进窗口

范围：REQ-UI-04、REQ-AI-06。分析结果进入 M2 的查询窗口（本迭代调整布局），图片多模态理解上线，截图开始被"看懂"。

### M7 越用越懂你

范围：REQ-AI-07、REQ-AI-08。画像聚合 + sqlite-vec 向量索引，兴趣图谱可视化。

### M8 主动回报

范围：REQ-AI-09、REQ-AI-10。基于画像的问答、推荐与主动洞察推送。M2 就埋下的来源 / 时间线数据在这里成为回答的引用来源。

### M9 终局旗帜（只立愿景，细节 M8 中期再补）

- LLM 调用脱敏配置
- 数据导出 / 迁移
- 打磨"silent partner"体验

## 迭代排布逻辑

- **M1 → M4 纯信息收集段，零 AI 依赖**；M4 完成即"信息收集能力健全"，是 AI 介入的前置条件（有意后置 AI）。
- **M5 → M8 AI 段严格线性**：流水线（M5）→ 呈现（M6）→ 画像（M7）→ 主动（M8），无回环。
- 依赖关系：M5 依赖 M1 的库；M6 依赖 M2 的窗口与 M5 的流水线；M8 依赖 M7 的画像。
