## 里程碑

### M0 骨架就绪 ✅

仓库结构落地：pnpm workspaces 根 + `apps/desktop`、`packages/ai`、`packages/shared` 三个空包。

### M1 手动输入入库

范围：REQ-CAP-02、REQ-CAP-05、REQ-STORE-01、REQ-TOOL-01、REQ-DX-02。

边界：只做「桌面宠物 + 输入框」的入库闭环，**不碰分析与历史 UI**。

> **2026-10-20 图文升级**：「仅支持文字、图片提示暂不支持」的边界作废——输入框升级为图文混合（REQ-CAP-02 新范围），粘贴与截图图片均进待提交区，详见变更记录。

交互方向（2026-10-16 变更）：点击桌面宠物唤出输入框，用户手动粘贴想摘录的内容、可编辑，确认后入库；**不再有任何全局热键、模拟复制（osascript Cmd+C）、剪贴板监听与 Accessibility 权限依赖**——这些已随旧方案整体移除。

**交互细节**（2026-10-16 对齐）：

- **桌面宠物**：带动效角色（idle 动效素材由用户提供，其余表情状态后续迭代再补）；
  默认停靠屏幕右下角，可拖动换位置但不记忆（每次启动回默认位）；单击唤出输入框；
  系统托盘图标提供退出入口。
- **输入框**：宠物旁边弹出；确认入库后输入框内显示"✓ 已拾光"轻提示 1~2 秒并自动
  收起；Esc、失焦 / 点击空白处均可收起。
- **内容规则**：~~仅文字~~（2026-10-20 起图文化，见变更记录），上限 5000 字（输入时拦截，实时字数统计如 4232/5000）；
  空内容确认按钮禁用；~~粘贴图片 / 文件提示"暂不支持"~~（2026-10-20 起粘贴图片进待提交区，文件仍不支持）。

### M2 查询页面

范围：REQ-UI-01、REQ-UI-02、REQ-UI-03。

边界：筛选维度为内容类型、时间范围、关键词搜索（M1 阶段 M2 仅文字类型可用，M4 截图接入后恢复文 / 图筛选）；不为分析结果预留展示位置，分析展示的排期后续迭代再定。

**性能待办**（继承 M1 对齐结论）：M2 需处理分页 / 懒加载 / 搜索索引，避免数据量上来后查询卡顿（高频使用数月后，全文关键词搜索与列表渲染是主要风险点）。

### M4 选区截图（✖ 已废弃，明确不做）

范围：REQ-CAP-03。~~类微信全屏遮罩选区；截图进入输入框待提交（配文字、多张累积），点「拾光」确认才入库~~

**2026-10-20 最终形态**：REQ-CAP-03 废弃——截图场景由「系统截图 / 微信截图 + 粘贴进输入框」承接（图文输入框升级的一部分），electron-snapora 遮罩链路移除，拾光零屏幕录制权限依赖。M4 交付的**图片存储管道**（records+attachments 两表、`shiguang-image://` protocol、记录页图片支持、删除级联）继续作为基础设施服务图文入库。注意：**只入库，不理解**——图片理解是 AI 能力，排期后续迭代再定。
